## Why It Failed Earlier

The `compose.yaml` file in your directory was an old configuration that:
- Didn't have backend service defined
- Didn't have MongoDB
- Didn't have environment variables
- Conflicted with the correct `docker-compose.yml`

When Docker Compose sees both files, it uses the alphabetically first one (`compose.yaml` comes before `docker-compose.yml`).

**Fixed by:** Deleting the old `compose.yaml` file.

If this happens again:
```bash
# Check which compose file is being used
docker-compose config | head -5

# If wrong file, delete it
Remove-Item D:\Quant\QuantG\compose.yaml -Force
```
