# AGENT_ROUTER.md — QuantG Symptom-to-File Decision Tree

**Read this when you have a symptom but don't know which file to open.**
**Find your symptom, open ONLY the listed files, run the listed test.**

Do not `grep` the entire codebase. Do not open `server.py` unless this document says so.

---

## Symptom: "P&L is wrong / always 0 / dashboard disagrees with strategy card"

- **Primary file**: `backend/core/portfolio_ledger.py` → `get_strategy_pnl_today()`
- **Secondary file**: `backend/server.py` → search `_get_todays_realised_pnl`
- **Source of truth**: `db.trade_fills` collection, `action` in `["CLOSE", "REDUCE"]`
- **Do NOT trust**: `strategy.today_pnl` field — it is a cached counter, not the source
- **Common causes**: fill not closing position, duplicate fill skipped, wrong lot_size, charges not subtracted
- **Test**: `python -m pytest tests/test_dashboard_truthfulness.py -v`
- **Tier**: 2

---

## Symptom: "Order not placed / signal not firing"

- **Primary file**: `backend/signal_manager.py` → `signal_manager_loop()`, pre-validation block
- **Check logs for**: `[LIMITS]` (strategy limits), `[QUALITY]` (option quality), `[RISK]` (risk rejection)
- **Log command**: `docker-compose logs backend --tail=100 | grep -E "LIMITS|QUALITY|RISK|FILTERED"`
- **Common causes**: `max_trades_day` reached, cooldown active, option quality score too low, strategy paused
- **Test**: `python -m pytest tests/test_signal_manager.py tests/test_risk_controls.py -v`
- **Tier**: 2

## Symptom: "Signal blocked / FILTERED with unexpected reason"

- **Primary file**: `backend/signal_manager.py` → `StrategySignalValidator.validate()`
- **Secondary file**: `backend/core/risk_manager.py` → `RiskManager.check_pre_trade()`
- **Check DB**: `db.signals.find({status:"FILTERED"}).sort({created_at:-1}).limit(10)`
- **Fields to inspect**: `rejection_reason`, `rejection_detail`
- **Tier**: 2

## Symptom: "Strategy not activating / stuck in PAUSED or DRAFT"

- **Primary file**: `backend/strategy_runner.py` → `_run_strategy_evaluation_loop()`
- **Check**: `db.strategies.find({status:"live"})` — is it actually live?
- **Check**: `CORE_ENGINE_ENABLED` and `CORE_ENGINE_PAPER_ENABLED` in `docker-compose.yml`
- **Common causes**: strategy in DRAFT, core engine flags off, no signals generated by Python code
- **Tier**: 2

---

## Symptom: "Position stuck in EXITING or PENDING_BROKER"

- **Primary file**: `backend/position_monitor.py` → `_check_position()`
- **Secondary file**: `backend/server.py` → `_close_strategy_positions()`
- **Check**: `db.strategy_positions.find({status:"EXITING"})` — look at `exit_attempt_at` timestamp
- **Rule**: positions stuck in EXITING > 5 min are auto-reverted to OPEN by the monitor
- **Rule**: after 3 genuine exit failures → `CIRCUIT_BREAKER` status — manual resolve required
- **Test**: `python -m pytest tests/test_position_monitor.py -v`
- **Tier**: 2

---

## Symptom: "Duplicate position created / phantom SHORT position"

- **Primary file**: `backend/core/portfolio_ledger.py` → `process_fill()`
- **Check**: `db.processed_fill_ids` unique index — if fill_id already there, fill is rejected
- **Common causes**: duplicate SELL fill processed twice, CLOSED LONG not found so new SHORT created
- **Fix pattern**: check for CLOSED/EXITING LONG before creating a new position from a SELL fill
- **Tier**: 3

## Symptom: "Wrong lot size in order / quantity looks wrong"

- **Root cause file**: `backend/core/market_domains.py` → `NSE_FO_DOMAIN.lot_sizes`
- **Current values**: NIFTY=65, BANKNIFTY=30, SENSEX=20 (verified Jan-2026, NSE circ FAOP70616)
- **There is no config.py copy** — `MARKET.*_LOT_SIZE` was deleted 2026-08-03 (dead code, and
  SENSEX had drifted to 10). `market_domains.py` is the only source.
- **Never hardcode**: always use `resolve_domain_by_underlying(underlying).get_lot_size(underlying)`
- **Test**: `python -m pytest tests/test_core_logic.py::test_nifty_lot_size -v`
- **Tier**: 1

## Symptom: "Kill switch not triggering / daily loss limit not working"

- **Primary file**: `backend/core/risk_manager.py` → lines checking `daily_loss_limit`
- **Secondary file**: `backend/server.py` → `_check_daily_loss_guard()`

## Symptom: "WebSocket disconnected / no live prices"

- **Primary file**: `backend/brokers/upstox_gateway.py`
- **Check logs**: `docker-compose logs backend --tail=50 | grep -i "websocket\|feed\|upstox"`
- **Check**: Upstox access token not expired — `db.broker_keys.find({user_id:"..."})`

## Symptom: "Frontend page blank / component crash"

## Tunable Constants — Where to Change Values

| What you want to change | File | Class/field |
|---|---|---|
| Lot sizes / strike intervals | `backend/core/market_domains.py` | `NSE_FO_DOMAIN.lot_sizes` / `.strike_intervals` (NOT config.py) |
| Default cooldown minutes | `backend/config.py` | `RISK.DEFAULT_COOLDOWN_MINUTES` |
| Option quality thresholds | `backend/config.py` | `OPTION_QUALITY.LIVE_MIN_SCORE` |
| Paper starting balance | `backend/config.py` | `PAPER_TRADING.STARTING_BALANCE` |
| Position monitor poll rate | `backend/config.py` | `MONITOR.POLL_IN_HOURS` |
| Actual lot sizes (authoritative) | `backend/core/market_domains.py` | `NSE_FO_DOMAIN.lot_sizes` |

- `frontend/src/pages/*.jsx` — UI only, no trading logic
- `backend/routes/auth.py` — auth only, no position/order logic

- `backend/core/portfolio_ledger.py` — accounting spine
- `backend/core/paper_broker.py` — wallet credits
- `backend/server.py` → `_close_strategy_positions()` — exit state machine
- `backend/brokers/upstox_gateway.py` — live broker connection
- `backend/core/execution_router.py` — order routing decision
