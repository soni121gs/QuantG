## MOST COMMON FIXES

### Fix 1: Allow Firewall Ports (Most Common)
```
In VPS terminal:
sudo ufw allow 3000/tcp
sudo ufw allow 8000/tcp  
sudo ufw reload
```

### Fix 2: Restart Containers
```
In VPS terminal:
docker-compose restart
docker-compose ps
```

### Fix 3: Check Logs
```
In VPS terminal:
docker-compose logs
```
Look for "ConnectionRefused" or "Error" messages
