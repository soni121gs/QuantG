# Participant OI Caveats

Core idea: participant-wise F&O open interest can describe positioning, but directional predictive power must be proven.

QuantG use: P3-5 treats participant OI as an overlay candidate only, not a standalone signal.

Research rule: wire participant OI only if it improves existing S3/S4 sleeves across regimes.

Kill criterion: reject if expectancy is near zero or sign-flips by year.
