## 📞 SUPPORT REFERENCE

### If Issues Occur

| Issue | Fix |
|-------|-----|
| Frontend shows v1.0 | `docker-compose down && docker system prune -a && docker-compose build --no-cache && docker-compose up -d` |
| API not responding | `docker-compose restart quantg-backend` |
| Database error | `docker-compose logs quantg-mongo` |
| Can't access VPS | Check firewall, SSH port, IP address |
| Performance slow | Check `docker stats`, increase resources |
| Orders failing | Verify Zerodha API, check order logs |
| Position mismatch | Run position reconciliation |
| Out of memory | `docker system prune -a` |
